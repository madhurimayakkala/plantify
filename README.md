# 🌱 Plantify

Plantify is a full-stack habit and goal tracking application that turns personal growth into a virtual gardening experience.

Users create habits, maintain daily streaks, and grow virtual plants through consistent progress. The project explores how gamification can make habit formation more engaging and rewarding.

## Features

- User authentication with Clerk
- Habit and goal management
- Daily progress tracking
- Streak tracking system
- Plant-growth visual progression
- Persistent cloud-based storage
- Responsive user interface

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Clerk Authentication
- Supabase
- Vercel
